# pca-lab: линейная алгебра в анализе портфеля

Учебный проект: как ковариационная матрица, спектральное разложение и квадратичные формы
работают в реальной задаче — анализе риска портфеля из 27 активов (25 акций США из 5 секторов,
облигации TLT и золото GLD) на дневных данных за октябрь 2021 – сентябрь 2026.

## Этапы

| # | Этап | Линейная алгебра | Ноутбук |
|---|------|------------------|---------|
| 1 | Цены и доходности | матрица данных R (T × N), линейность r_p = wᵀr | [01_returns](notebooks/01_returns.ipynb) |
| 2 | Ковариационная матрица | Σ = XᵀX/(T−1), положительная полуопределённость, обусловленность | [02_covariance](notebooks/02_covariance.ipynb) |
| 3 | PCA | Σ = QΛQᵀ, собственные векторы как факторы, связь с SVD | [03_pca](notebooks/03_pca.ipynb) |
| 4 | Риск портфеля | квадратичная форма √(wᵀΣw), разложение риска | [04_portfolio_risk](notebooks/04_portfolio_risk.ipynb) |
| 5 | Mean-variance optimization | лагранжиан, Σ⁻¹, shrinkage | [05_optimization](notebooks/05_optimization.ipynb) |
| 6 | Отчёт | допущения, результаты, ограничения, переобучение | в работе |

## Ключевые результаты на данный момент

- Средняя корреляция внутри сектора — 0.54, между секторами — 0.15.
- PCA на корреляционной матрице: PC1 «рынок» объясняет 26% дисперсии; PC2–PC4 — длинно-короткие
  факторы «защитные против нефти», «нефть против технологий», «технологии против банков».
- Слепой тест: по весам в PC2–PC5 без названий активов k-means восстанавливает все 6 групп (27 из 27 активов).
- Корреляции нестабильны: между двумя половинами периода в среднем меняются на 0.13.
- Портфель минимального риска держит обещание: на данных вне обучения риск 8.8% при прогнозе 8.6%,
  и снижение риска относительно 1/N (11.7%) отличимо от шума.
- MaxSharpe без ограничений — лучший задним числом (Sharpe 2.66) и худший вне обучения (0.36 при 1.80 у 1/N).
  Главная причина — оценка доходности: её ошибка за два года (19%) равна типичной величине самой доходности.
- Преимущества стратегий по Sharpe над 1/N статистически не доказаны: на трёх годах теста 95% интервалы накрывают ноль.

## Документация

- [Метод множителей Лагранжа](docs/lagrange_multipliers.md) — как одна идея (касание линии уровня
  и ограничения) даёт и PCA ($\Sigma v = \lambda v$), и портфель минимального риска ($w \propto \Sigma^{-1}\mathbf 1$).

## Структура

```
src/
  data.py   — загрузка цен (yfinance, локальный кэш), доходности
  risk.py   — ковариация, корреляция, спектр, число обусловленности
  pca.py    — спектральное разложение, доли дисперсии, ряды факторов
  plots.py  — графики
  optimize.py — оптимизация портфеля (min variance, max Sharpe, граница эффективности)
  backtest.py — walk-forward тест, метрики, бутстрэп разностей
notebooks/  — по ноутбуку на этап, с выводами и формулами
docs/       — разборы математики
reports/figures/ — сохранённые графики
```

## Запуск

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/jupyter lab
```

При первом запуске цены скачиваются с Yahoo Finance и кэшируются в `data/prices.csv`
(в репозиторий не входят).
